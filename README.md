# Google Maps Lead Scraper & Website Quality Analyzer

**An autonomous AI-powered scraping and analysis tool for finding qualified web design leads.**

</div>

## 📌 Overview

This project is a sophisticated AI agent designed to search Google Maps for commercial businesses within specific sectors and geographic areas. Its primary mission is to identify businesses that either:
- **Do not have a website**
- **Have an outdated, low-quality, or poorly designed website**

The ultimate goal is to generate highly qualified leads for website redesign or creation services.

## ✨ Features

- **Geographic Targeting**: Restrict searches to configurable, specific geographic areas.
- **Sector-Specific Searching**: Target particular business sectors (e.g., restaurants, mechanics, salons).
- **Data Collection**: Automatically extract business information from Google Maps and the web.
- **Website Detection**: Verify if a business currently operates a website.
- **Quality Evaluation**: AI-driven analysis of existing websites to determine their quality and design state.
- **Structured Output**: Export all collected data and analysis into structured spreadsheets for easy integration into CRM systems.

## 🚀 How It Works

1. **Configuration**: Define your target area and business sector.
2. **Scraping**: The agent searches Google Maps and gathers business details.
3. **Analysis**: It checks for web presence. If a website exists, it performs a quality check based on modern design standards.
4. **Export**: Results are compiled into a comprehensive lead list, highlighting the most promising prospects.

## 🛠 Tech Stack

- **Python** for core logic and execution
- **Web Scraping** tools for data extraction
- **AI/LLM** integration for website quality evaluation
